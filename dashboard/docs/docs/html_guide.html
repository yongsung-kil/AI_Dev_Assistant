HTML 작성 가이드

이 저장소와 플러그인이 만드는 모든 html(대시보드, 문서 페이지, 소개 페이지)의 규격 정본이다. 페이지를 만들거나 렌더러를 고칠 때 이 문서를 먼저 읽는다.

1. 파일과 링크

  • ㉮ 정적 파일이다. 서버 프로그램 없이 파일을 열어도 동작하고, 어느 서버에 올려도 그대로 동작한다
  • ㉯ 링크는 상대 경로만 쓴다. 절대 주소와 호스트 이름을 넣지 않는다
  • ㉰ 외부 자원(CDN의 스크립트, 글꼴, 스타일)을 불러오지 않는다. 스타일과 스크립트는 assets/ 안의 파일이거나 페이지 안에 둔다 (사내망에서 바깥이 막혀도 열린다)
  • ㉱ 한글 파일 이름은 href에서 퍼센트 인코딩한다
  • ㉲ md가 정본인 문서는 html을 손으로 고치지 않고 렌더러를 고쳐 다시 만든다. 소개 페이지처럼 html이 정본인 것은 그 사실을 파일 머리 주석에 적는다

2. 틀

자리내용참고 사이트 메모의 출처
왼쪽 사이드바큰 장과 그 아래 작은 장. 장마다 접었다 편다 (details 요소). 현재 페이지를 표시1, 2, 3
위검색 상자. 제목과 본문을 찾아 결과 목록을 보인다1
오른쪽"이 페이지의 차례" (h2, h3). 스크롤에 따라 현재 절 표시3
가운데본문. 최대 폭 880px
첫 화면진행 중인 일을 카드로. 카드를 누르면 상세 문서로 간다4
변경 이력커밋 단위가 아니라 작업 단위 (완료 이력에서)5
빠른 시작소개 페이지에 다섯 단계 안의 시작 안내6
  • ㉮ 휴대폰 폭(600px 아래)에서는 사이드바와 오른쪽 차례를 접고 본문만 보인다. 가로 스크롤이 생기지 않게 한다
  • ㉯ 표는 넘치면 표 안에서만 가로 스크롤한다

3. 색과 글꼴

  • ㉮ 색은 :root의 css 변수로 정의한다: --bg, --surface, --text, --muted, --border, --accent, --ok, --warn
  • ㉯ 어두운 모드는 @media (prefers-color-scheme: dark)에서 같은 변수만 다시 정의한다
  • ㉰ 글꼴은 시스템 글꼴 묶음: "Segoe UI", "Malgun Gothic", "맑은 고딕", "Apple SD Gothic Neo", sans-serif. 코드는 Consolas, "D2Coding", monospace
  • ㉱ 본문 16px, 줄 간격 1.7. 제목은 계층대로만 (h1 하나, h2와 h3로 나눔)
  • ㉲ 대비는 본문 글자와 바탕이 4.5:1 이상

4. 문장

  • ㉮ 꾸미는 말과 감탄을 쓰지 않는다. 기능은 하는 일로 말한다 ("검색한다", "카드를 누르면 상세로 간다")
  • ㉯ 줄글 대신 표, 카드, 목록, 흐름 그림으로 구성한다. 문단은 한 가지만 말한다
  • ㉰ 줄표(U+2014)와 가운뎃점(U+00B7)을 쓰지 않는다. 약어는 첫 등장에서 풀어 쓴다
  • ㉱ 회사 이름, 사업 도메인 이름, 입력 파일의 출처를 적지 않는다

5. 요소

  • ㉮ 카드: 제목, 한 줄 설명, 진행률 막대(하위 단계 완료 수 / 전체), 링크
  • ㉯ 표: 머리 행 고정, 짝수 행 옅은 바탕
  • ㉰ 접기: details와 summary. 기본은 현재 장만 펼침
  • ㉱ 상태 표시: 미답 결정은 --warn, 완료는 --ok
  • ㉲ 코드: pre code, 가로 스크롤

6. 검사

  • ㉮ 렌더 뒤 상대 링크가 가리키는 파일이 모두 있어야 한다 (렌더러가 검사하고 보고)
  • ㉯ 금지 표현 0건, 줄표와 가운뎃점 0건
  • ㉰ 파일을 두 번 만들어도 생성 시각 줄 말고는 같아야 한다
