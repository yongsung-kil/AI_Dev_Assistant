# ADR (설계 결정 기록)

> 코드에서 읽을 수 없는 것(왜 이 선택을 했는가, 무엇을 거부했는가)만 기록한다. 관련 모듈을 바꾸기 전에 읽는다.

## 목록

| 번호 | 제목 | 상태 | 날짜 |
|---|---|---|---|

## 양식

파일 이름은 `ADR-{NNN}-{제목}.md`, 길이는 300토큰 안팎.

````markdown
# ADR-NNN: {제목}

상태: 채택 | 추정 | 대체됨 | 날짜: YYYY-MM-DD

## 제약
{이 결정을 강제한 조건}

## 결정
{무엇을 택했는지}

## 거부한 대안
{무엇을 왜 택하지 않았는지}

## 결과
{이 결정 때문에 생긴 규칙이나 비용}
````
