# 교체 지점 (새 기법을 끼워 넣는 자리)

> onboard 스킬이 채우고 idea-apply 스킬이 쓴다. 교체 지점이란 본체가 어떤 단계를 일부러 따로 떼어 두어, 새 버전이 그 부분만 갈아 끼울 수 있게 만든 자리다.

## 1. 교체 단위

(이 프로젝트에서 갈아 끼우는 단위. 예: 기본 클래스를 상속해 메서드 하나 재정의, 함수 포인터 교체, 모듈 인스턴스 교체. 아직 없으면 "없음, 만들어야 함"이라고 적고 4절에 만드는 방법을 적는다)

## 2. 교체 지점 표

| 바꿀 수 있는 것 | 교체 단위 | 위치 (파일:줄) | 입력 | 출력 | 상태 |
|---|---|---|---|---|---|

상태 값: 있음 | 만들어야 함 (후보 자리를 위치에 적는다)

## 3. 교체 지점에 맞지 않는 변경

(전체를 다시 써야 하는 종류의 변경과, 그때 재사용할 수 있는 부품)

## 4. 새 버전을 붙이는 절차

- 1. (양식 복사)
- 2. (재정의)
- 3. (기준 실험과 비교하는 방법)
