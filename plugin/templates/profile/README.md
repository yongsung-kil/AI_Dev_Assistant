# 프로젝트 프로파일

이 폴더의 다섯 문서가 이 프로젝트에 대한 지식의 정본이다. 플러그인의 스킬은 코드를 넓게 읽는 대신 이 문서를 읽는다.

| 문서 | 담는 것 | 채우는 스킬 |
|---|---|---|
| overview.md | 문제 정의, 입력과 출력, 성능 지표, 실행 환경 | onboard |
| structure.md | 모듈 지도, 호출 관계, 데이터 흐름 | onboard, explore |
| replacement_points.md | 새 기법을 끼워 넣을 수 있는 자리 | onboard, idea-apply |
| techniques.md | 이미 가진 기법 | onboard, paper-screen |
| constraints.md | 변경 금지 대상, 기밀 규칙, 용어 풀이 | onboard |

- ㉮ 언어에 기대지 않는 낱말(모듈, 인터페이스, 교체 지점, 신호)로 적는다
- ㉯ 코드를 직접 읽고 확인한 것만 적고, 근거 파일과 줄을 붙인다
- ㉰ 모르면 "미확인"이라고 적는다. 추측하지 않는다
- ㉱ 코드가 바뀌면 이 문서를 먼저 고친다 (변경 시점은 git 이력이 담당한다)
