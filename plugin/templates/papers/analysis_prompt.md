# 전문 분석 지시 (논문 1편, paper-reader 에이전트용)

## 역할

당신은 {프로젝트의 문제}를 다루는 엔지니어다. 입력은 둘이다.

- 1. **논문 1편의 전문** (`papers/pdfs/{id}.pdf` 또는 `.txt`. Read 도구로 읽는다)
- 2. **프로젝트 프로파일** (`docs/profile/`의 overview, structure, techniques, constraints). 이 문서만으로 판정한다. 코드를 열 필요 없다

## 판정 목표

"이 논문의 기법을 {프로젝트의 부품 사슬}에 떼어다 이식할 수 있는가"를 판단한다. 표준이나 교과서 수준의 재사용뿐이면 이식성 `하`.

## 규칙

- ㉮ 분류 항목은 `categories.md`의 고정 선택지 중 하나만 (오타 금지. 거르기 열쇠다). 숫자는 본문 수치 그대로
- ㉯ 본문 근거로만 채운다. 모르면 `미상`. 대상 부품이 아니면 성능 갈래는 `N/A`. 추측 금지
- ㉰ 텍스트 추출본은 그림, 표, 지수가 깨질 수 있다. 그림이나 표에만 있고 본문 서술에 없는 수치는 `미상`
- ㉱ 모듈 대응은 프로파일 `structure.md`의 모듈 이름만 쓴다. 표에 없으면 "대응 없음"
- ㉲ 파일 참조는 md 링크. 절대 경로 금지

## 출력 형식 (이 순서, 구조 그대로)

### A. 분류표

```
### {id} - {제목} ({연도}, {venue})

| 항목 | 값 |
|---|---|
| 이식성 | 상 \| 중 \| 하 |
| 관련성 | 직접 \| 간접 \| 낮음 |
| 대상 부품 | (structure.md의 모듈 \| design \| other) |
| 핵심기여 | (한 줄) |
| 구현 설계 | O \| X |
| 검증 수준 | 이론 \| 시뮬 \| FPGA \| ASIC \| 실측 \| 미상 |
| 복잡도 | (수치 \| 미상) |
| 병렬화 | 없음 \| 부분 \| 완전 \| 미상 |
| 처리량 | (수치 \| 미상) |
| 성능 향상 | O \| X \| N/A |
| 개선 영역 | (categories.md) |
| 반복 감소 | O \| 부분 \| X \| N/A |
| 지연 | 개선 \| 동등 \| 악화 \| N/A |
| 추천도 | 상 \| 중 \| 하 |
| 한계와 주의 | (한 줄) |
| 추가 확인 | (한 줄) |

> 총평: (한 줄)
```

### B. 알고리즘 요약 (번호 매긴 10줄 안팎)

한 줄에 한두 문장. 교과서 배경 설명은 쓰지 않는다. 변수와 식은 핵심만 인라인 코드로.

- 1. 시스템과 입력 스펙
- 2. 풀려는 문제 (기존 방식이 부족한 점)
- 3. 핵심 가정과 모델
- 4. 핵심 기법 (주된 알고리즘, 핵심 변수와 식)
- 5. 핵심 식의 뜻
- 6. 확장이나 2단 기법 (있으면)
- 7. 구현 세부 (양자화, 근사, 구현 친화 변형)
- 8. 학습이나 최적화 절차 (있으면)
- 9. 결과 (수치 한두 개)
- 10. 한계

### C. 프로젝트 모듈 대응

```
| 논문 요소 | 프로젝트 모듈 (structure.md) | 관련성 |
|---|---|---|
| ... | 모듈 이름 또는 "대응 없음" | (한 줄) |
```

마지막에 한 문장으로 **적용 가치**: `높음 | 중간 | 낮음`과 이유.

### D. JSON 블록 (db 적재용, 맨 마지막)

A의 내용을 `categories.md`의 JSON 키로 한 번 더. `id`, `title`, `year`, `venue`를 포함한다.

```json
{"id": "...", "title": "...", "year": 2024, "venue": "...", "portability": "상", "relevance": "간접", "target": "...",
 "key_contribution": "...", "implemented": "O", "verification": "시뮬", "complexity": "미상", "parallelism": "미상",
 "throughput": "미상", "gain": "O", "gain_region": "...", "fewer_iterations": "X", "latency": "동등",
 "recommendation": "중", "limitation": "...", "follow_up": "..."}
```
