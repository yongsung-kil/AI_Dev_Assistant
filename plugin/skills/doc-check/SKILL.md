# 문서 검사

문서를 고쳤으면 커밋 전에 이 절차를 돈다. 검사 스크립트는 이 스킬의 기준 폴더에서 `../../scripts/doc_check.py`다 (스킬을 부를 때 표시되는 기준 폴더 기준).

## 절차

- 1. 고친 md 파일(또는 폴더)을 대상으로 스크립트를 돌린다
   ```bash
   python "<이 스킬의 기준 폴더>/../../scripts/doc_check.py" <파일 또는 폴더>... [--terms <금지 낱말 파일>]
   ```
   출력은 `경로:줄: [규칙] 설명` 이고 마지막 줄이 `발견 N건`이다
- 2. 발견마다 그 문장을 다시 쓴다. 뒤에 단서를 덧붙이지 않는다
   - ㉮ 글자: 줄표는 접속사, 쉼표, 괄호로. 가운뎃점은 쉼표로. 수식의 곱셈 기호는 예외이니 인라인 코드로 감싼다
   - ㉯ 링크: 파일 위치를 찾아 상대 경로를 고친다. 한글 경로는 퍼센트 인코딩한다
   - ㉰ 낱말: 금지 낱말은 그 뜻을 풀어 쓴 말로 바꾼다
- 3. 스크립트가 잡지 못하는 것을 눈으로 본다
   - ㉮ 조건이나 항목 나열에 번호가 빠진 곳
   - ㉯ 번호 나열의 항목별 줄바꿈 (본문은 불릿, 표 칸 안은 `<br>`)
   - ㉰ 기계 치환 후유증: 조사 어긋남, 이름 중복, 부분 문자열 오염
- 4. 0건이 될 때까지 1로 돌아간다. 0건이면 커밋한다

## 규칙의 근거

- ㉮ 줄표와 가운뎃점은 접속과 나열을 흐리게 하므로 접속사와 쉼표로 쓴다
- ㉯ 번호가 없는 나열은 가리켜 말할 수 없다
