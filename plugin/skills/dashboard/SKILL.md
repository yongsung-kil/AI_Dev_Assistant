# 대시보드

`dashboard/` 아래에 정적 html을 만든다. 규격은 HTML 작성 가이드(플러그인 저장소의 `docs/html_guide.md`)를 따른다. 스크립트는 이 스킬의 기준 폴더에서 `../../scripts/`에 있다.

## 읽는 자료

| 자료 | 파일 | 읽는 규칙 |
|---|---|---|
| 작업 | `_pm/TODO.md` | "작업 목록" 절의 `- [ ]`와 `- [x]` 항목, 2칸 들여쓴 하위 단계, `- 상세:` 링크 |
| 완료 | `_pm/DONE.md` | `### YYYY-MM-DD 제목` 절과 다음 줄의 요약 |
| 결정 대기 | `_pm/tasks/**/판정요청*.md` | `## 물음 N.`과 그 뒤 `%` 줄 (`%`뿐이면 미답) |
| 아이디어 | README의 표 | 머리 칸에 `#`, `제목`, `상태`가 든 표 |
| 실험 | `실험로그.md` | `## ` 절 |
| 문서 지도 | `docs/`, `_wiki/`, `_pm/`, `ideas/`, `papers/`, `optim/`, 루트 README와 CLAUDE.md | 머리말 `title`과 `tags`, md 링크로 들어오고 나가는 관계 |
| 논문 | `papers/papers.db` | papers 표(출처, 연도, 상태)와 analysis 표(분석 JSON). paper 스킬들이 채운다 |

파일 위치가 다르면 `dashboard/config.json`에 적는다 (양식은 플러그인의 `templates/dashboard/config.json`). 사이드바 묶음도 같은 파일의 `sidebar` 목록이 정한다: 묶음 이름과 그 묶음에 드는 폴더나 md 경로. 기본은 온보딩(`docs/usage.md`, README, CLAUDE.md, `docs/profile/`, `docs/explore/`, `docs/adr/`), 작업 관리(`_pm/`), 외부 기술문서(`papers/`, 논문 탐색기와 특허 탐색기가 맨 위), 아이디어 적용(`ideas/`), 최적화(`docs/speed_opt/`, `docs/robustness/`, `optim/`), 내부 기술문서(`_wiki/`)이고, 어디에도 들지 않는 문서는 "기타 문서"로 간다.

## 절차

- 1. 프로젝트 루트에서 `python "<이 스킬의 기준 폴더>/../../scripts/render_dashboard.py" .`를 돌린다. status.json 수집과 렌더를 한 번에 한다
- 2. 출력의 "깨진 링크"를 본다. 플러그인이 만든 문서(`_pm/`, `docs/profile/`, 아이디어 README와 실험로그)의 링크는 고치고 다시 돌린다. 사용자가 원래 갖고 있던 문서의 깨진 링크는 고치지 않고 목록으로 보고만 한다 (프로젝트 밖을 가리키는 링크는 사본이나 부분 저장소에서 정상이다). 링크가 md를 가리키는데 그 md가 문서 폴더 밖에 있으면 config.json의 `doc_dirs`에 폴더를 더한다
- 3. `dashboard/index.html`을 연다 (Windows는 `start dashboard/index.html`, macOS는 `open`, Linux는 `xdg-open`)
- 4. 산출물을 커밋할지는 프로젝트 규칙대로 (사이트로 올리는 저장소는 추적하고, 그렇지 않으면 `.gitignore`에 `dashboard/`)

## 화면

- ㉮ 위: 사이드바 접기 버튼, 프로젝트 이름, 검색 상자(제목과 본문, Ctrl K), 테마 전환(시스템, 밝게, 어둡게)
- ㉯ 왼쪽: 대시보드와 변경 이력 링크, 그 아래 일 갈래 묶음(온보딩, 작업 관리, 외부 기술문서, 아이디어 적용, 최적화, 내부 기술문서)과 그 안의 폴더와 문서. 깊을수록 글자가 작아지고, 묶음과 폴더마다 접었다 편다. 현재 페이지가 든 폴더는 펼쳐지고 답 대기 판정요청에는 미답 수 배지가 붙는다. 한 폴더에 문서가 40편을 넘으면 그 뒤는 "외 n편"으로 줄이고 검색으로 찾는다
- ㉰ 가운데 첫 화면: 계획, 진행 중, 완료 세 칸의 작업 보드(카드에 진행률과 백분율, 누르면 태스크 문서), 결정 대기(미답 수), 아이디어 현황표, 최근 실험 5건, 문서 지도(들어오는 링크 수, 연결 없는 문서 표시)
- ㉱ 변경 이력 페이지(`changelog.html`): `_pm/DONE.md`의 완료 작업을 날짜별 카드로. 기간(from, to)과 달 탭으로 거른다
- ㉲ 오른쪽: 이 페이지의 차례 (h2, h3). 현재 절을 세로 선에 표시
- ㉳ 문서 페이지: md를 그대로 html로. md 링크는 html 링크로 바뀐다
- ㉴ 논문 탐색기(`papers.html`, `papers/papers.db`가 있을 때): 검색어, 연도 범위, 출처, 상태, 분석 JSON의 갈래(서로 다른 값이 12개 이하인 항목)로 거르고, 제목을 누르면 분석 문서로, 분석이 없으면 원문 주소로 간다. 특허 탐색기는 같은 페이지에서 출처를 특허로 고정한 것. 분석 문서(`papers/analysis/`)는 수천 편일 수 있어 사이드바 없는 가벼운 틀로 만들고 검색 색인에는 제목만 넣는다
